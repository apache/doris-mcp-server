# Apache Doris MCP Server 1.0.0 发布说明

[English](1.0.0.md) | 简体中文

**Release Tag：**`1.0.0`  
**发布时间：** 2026-08-01  
**协议基线：** MCP `2026-07-28`  
**最低 Apache Doris 版本：**`3.0.0`

GitHub 详细发布记录：
[[RELEASE] Apache Doris MCP Server 1.0.0 Release](https://github.com/apache/doris-mcp-server/issues/189)。
进入 sdist 的兼容发布说明仍位于
[docs/release-notes-1.0.0.md](../release-notes-1.0.0.md)。

## 概要

1.0 建立了 MCP Host/AI Agent 连接 Apache Doris 的第一套稳定公共架构。它把
1.0 以前相互独立的直接 Tool 重构为一套能力感知、只读合同：

- 8 个稳定一级领域；
- 47 个精确 Child 能力；
- 确定性渐进发现与 Flat 回退；
- 运行时版本、特性、Provider、路由与权限证据；
- 精确 Schema、Authorization ID 和类型化 Result/Error Envelope；
- Streamable HTTP 与 stdio 上的 MCP `2026-07-28`；
- 有界、Fail Closed 的安全与可靠性行为。

MCP 协议合同在支持传输上达到 GA。部分分布式部署形态仍有意受限，因此 Python
Package Classifier 仍为 Beta。

## 架构变化

默认情况下 Host 只看到 8 个完整问题域。它先用 `{}` 调用领域，获得完整的已授权
Child Manifest 与精确 Schema，再使用精确 Child 与参数调用同一个领域。

这是确定性 Progressive Disclosure，不是概率 Server-side Intent Routing。所有
Domain 一直注册，因此模型可以在同一对话中从 Catalog 切换到 Cluster。不能执行
两步发现的 Host 可以使用启动级 `flat` 模式，以正式名称获得相同 Child。

同一个 Catalog 驱动 Hierarchical、Flat、Authorization、Handler Binding、自动
生成文档和测试。1.0 以前名称直接移除，不留 Alias 窗口。

| Domain | Child 数量 | Release Scope |
|---|---:|---|
| `doris_catalog` | 5 | Catalog、Database、Table、四 Section Context、Size |
| `doris_query` | 7 | 有界 Query、Explain、Profile、Diagnosis、Slow Query、ADBC |
| `doris_cluster` | 11 | Topology、Task、Metric、Memory、Cache、Compaction、Workload、Capability |
| `doris_pipeline` | 5 | Ingestion、Diagnosis、MV、Freshness、Dependency |
| `doris_search` | 4 | Text/Vector/Hybrid、Analysis、Index、Diagnosis |
| `doris_governance` | 8 | Column、Storage、Lineage、Access、Audit、UDF、Auth Mapping |

全部 Child 名称和 Binding 见[工具领域](../capabilities/tool-domains.zh-CN.md)与自动
生成[工具目录](../tool-registry.md)。

## 能力感知发现

每个已授权 Child 的结构化 Availability 综合：

- 归一化 Doris 三位数版本与组件向量；
- 实时 SQL/Metadata/HTTP Probe；
- Deployment Mode 与路由一致性；
- Optional Provider Readiness/Generation；
- 精确 MCP Permission 与 Doris Visibility；
- 配置的安全策略。

已授权但不可用 Child 以 `callable=false` 和稳定 Reason Code 保留；未授权 Child
隐藏。Route/Provider/Permission 代际变化使 `manifest_version` 失效并要求重新
发现。

`Doris version doris-3.0.3-rc03-... (Cloud Mode)` 等真实版本返回值会归一化为
`3.0.3` 参与能力与认证。RC/GA 文本和 Commit Metadata 不创建独立支持结果。

## MCP `2026-07-28`

- stdio 与 Streamable HTTP 共用 SDK v2 协议核心。
- 现代请求无状态且自包含。
- 可选 `server/discover` 与确定性产品身份。
- 现代 `_meta` 与 HTTP Header 一致性校验。
- 有界分页 List 与绑定 Principal/Scope/Snapshot 的 HMAC Cursor。
- 有界 JSON Schema 2020-12 Definition、Argument 与 Structured Output。
- 清洗后的 W3C Trace Context 传播。
- 诚实 Subscription 边界：没有真实跨 Worker Event Source 就不提供
  `subscriptions/listen`。
- 默认关闭、隔离在 `/mcp/legacy` 的 `2025-11-25` HTTP Migration Adapter。

## 安全

- Static Bearer Token、JWT、External OAuth/OIDC 与 Doris OAuth 边界。
- 精确 MCP Operation、Domain Discovery、Child Execution Scope。
- 请求级 Doris OAuth/Static-token/Global 连接路由。
- Doris RBAC 对 Metadata/Data Visibility 最终生效。
- 中央 Read-only SQL/Identifier/Parameter Guard。
- Query Timeout、Row、Byte、Complexity、Collection 与 Schema Ceiling。
- Result Masking 与敏感 Metadata/Error Redaction。
- Host/Origin、Trusted Proxy、Non-loopback Authentication 与 HTTP Destination
  Policy。
- Digest-only Managed Token 持久化与受保护 Token Management 边界。
- 显式 Allowlist Custom Provider，不静默加载代码。
- 预留 `doris_admin` 不注册。

## 可靠性

- 分离 `/live` 与 Doris-backed `/ready`。
- Route-aware Connection Pool、Cancellation Disposal、Health Recovery 与多 FE。
- Private Capability TTL/Cache/Singleflight 和有界 Stale Fallback。
- 确定性 Stale/Unavailable/Invalid/Timeout/Execution Error Class。
- 只有合同明确可选证据才允许 Partial Success。
- Response 发送前执行 Output Schema Validation。
- Request ID、Duration、Source、Warning、Truncation 与清洗 Trace。
- Cluster、Search、Lakehouse、Lineage 的显式 Native/Fallback Path。

## 原生血缘与语义 Grounding

Doris 4.0.6+ 可以消费 Companion Producer 写入可查询 Lineage Store 的规范事件。
Native 模式要求实时 Provider/Store 证据。4.0.6 以前以有界 Audit Inference 为主要
路径；之后在 Native 不可用时作为显式 Degraded Fallback。

可选 Semantic Domain 消费经过审查的 Apache Ossie Model 进行只读 Grounding。
每个 Model-specific Operation 要求精确 `model_ref`；私有 Doris Binding 保留在
Server 侧。集成不会创作模型，也不会编译/执行语义表达式。

## 破坏性变化

- 移除全部 1.0 以前直接名称与 Alias。
- 默认使用 Hierarchical Exposure。
- 引入 Formal Flat Name 与精确 Scope。
- 引入 Manifest Availability 与 Stale Generation。
- 5 个 Table Call 合并到 `get_table_context` Section。
- ADBC 进入 Query Domain。
- Semantic Call 要求精确 `model_ref`。
- 现代 HTTP 在 `/mcp` 统一为 MCP `2026-07-28`。
- Legacy Protocol 与 Administration 保持隔离/默认关闭。

升级前阅读[迁移到 1.0](../migration/1.0.0.zh-CN.md)。

## 已知限制

- Doris OAuth 状态在进程内，要求单 Worker。
- ADBC 在 Token 绑定路由上 Fail Closed。
- Ossie 集成只做可选只读 Grounding。
- Native Lineage 异步 Best-effort，依赖 Provider。
- Audit Lineage/Dependency Inference 有界，可能不完整。
- Subscription/Change Notification 仍不可用。
- Public Reverse Proxy Host/Origin 需要部署级 Review。
- 该 Release 边界只有 Doris 4.0.5 已认证。
