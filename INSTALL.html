📦 doris-mcp-server 安装指南

版本 1.3.1

前置条件

OSLinux x86_64
Doris与 MCP Server 同机，FE 端口 9030，admin 免密
端口默认 3000

安装（3 步）

① 解压

tar xzf doris-mcp-server-1.3.1-linux-x64.tar.gz
cd doris-mcp-server

② 配置

编辑 mcp-server.toml，一般无需改动。如需改端口：

# mcp-server.toml
[server]
mcp_port = 3000     # 换成你的端口

③ 启动

# 前台
bash start-mcp-server.sh

# 后台
nohup bash start-mcp-server.sh > /tmp/doris-mcp.log 2>&1 &

看到 Uvicorn running on http://0.0.0.0:3000 表示成功。

首次启动

Admin 首次登录 WebUI 后自动创建 example 工作区，含：

dw.orders12 条示例订单
dw.users5 条示例用户
dw.products5 条示例商品
dw.dim_date365 天日期维度

5 个示例指标：total_amount、order_count、avg_amount、unique_users、user_count

默认不自动部署（seed_example = false），可使用 Reload 右侧的 Admin 专属按钮手动部署。设置为 true 后，Admin 首次登录时自动部署。

验证

WebUI：浏览器打开 http://<IP>:3000/mcp/web，用 admin:admin 登录。

Agent：Claude Code 中配置：

claude mcp add --transport http doris http://<IP>:3000/mcp \
  --header "Authorization: Bearer admin:admin"

然后对话输入 "检查服务健康状态" 验证。

常用操作

停止fuser -k 3000/tcp
升级停止 → 解压新版覆盖 → 重启
日志审计日志 ./logs/audit.log（路径见 mcp-server.toml 的 [logging] 配置）

可用 MCP Tool

Tool用途
get_query_guideAgent 工作流指引（第一步必调）
check_service_healthDoris 连通性 + workspace 状态
list_metrics列出可用指标
list_dimensions_for_metric查看指标的可用维度
query_metric核心查询，编译 + 执行语义 SQL
reload_semantic_layer手动触发重载
list_databases列出数据库
list_tables列出表名
describe_table查看表结构
execute_query裸 SQL（仅只读），语义层兜底

常见问题

端口被占fuser -k 3000/tcp 或换端口
Agent 401Token 格式 用户名:密码
workspace not_ready登录 WebUI → Validate 查看错误
Doris 连不上确认 FE 在 127.0.0.1:9030，admin 免密
